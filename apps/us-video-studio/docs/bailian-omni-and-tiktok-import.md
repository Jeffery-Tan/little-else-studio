# 百炼声画接入与统一参考视频任务

日期：2026-09-21。线路：US。范围：独立制片室视频创作 Agent。

## 已实现：百炼北京 Omni

用户选择复用 Wan 所在百炼体系。素材面板发现有效北京配置时，视频分析优先展示 `qwen3.8-omni-flash`。只读页面仅检查凭据文件存在及公开元数据，不解密密钥。显式提交分析后核对展示的endpoint、模型、设置版本与素材SHA-256，再冻结已有凭据；不复制密钥、不改写创作团队路由。图片及普通兼容视觉连接保持原功能。

输入原视频与可用音轨，沿用64 MiB上传、90秒分析限制。百炼内联视频Base64须小于10 MB，7,000,000字节以上的视频先用PyAV编码较小H.264画面并复用原音频包。原件保留；原件和实际输入均记录hash、时长及音轨时间范围。副本过大、解码失败、音轨时间偏移明显均在模型调用前失败。多音轨当前需先明确选用一条。保留原音轨不代表画面无损。

原生适配器固定北京业务空间，单次SSE、文本输出、`reasoning_effort=low`、最多4096输出Token。逻辑请求快照含实际媒体输入，保存于原run的Git外目录，密钥不进入快照。中断、取消、HTTP错误及格式错误不自动重试。未知用量不算零；模型返回完整用量但观察解析失败仍保留计费。

价格快照：北京每百万输入Token ¥0.8、输出Token ¥2.7，2026-09-21核对；缓存按未命中原价保守估算。Ledger沿用token计量并另存人民币单价与估算，不冒充美元、不换算汇率。原美元预算不覆盖人民币，原token软阈值仍适用。页面和CSV分币种，实际费用以百炼账单为准。

候选按时间段保存画面、声音、声画关系、参考机制和限制。没有音轨不得记录听到内容，部分音轨范围需明示；完全无音轨的区间不得补造声音。采用绑定素材字节与候选hash，机制仅在全部支持观察获选后进入证据。参考内容不是本款商品性能事实，也不构成成片或生成批准。

当前不包含局部高密度复查工具和自动成片验收。模型采样与时间估计不保证逐帧看听。尚未用真实账户调用；模型权限、账单与内容识别质量仍待实测，离线测试不能代替。

此前Omni专项17项通过（真实本地编解码、假模型）；本轮统一参考任务验证结果在验收节记录。

## 已实现：本地视频 / TikTok 链接 → 分析 / 复刻

代码已实现统一参考任务，离线验证不代表实际链接成功率或识别质量已验收。运行环境需要安装 requirements-runtime.txt 中固定的 yt-dlp 依赖，并重新加载服务。

用户进一步明确：提供参考视频必然是为了分析或复刻；手上有原视频和只有视频链接，是两个输入场景。取消此前“导入参考 / 导入并分析”的业务动作拆分，不增加仅存档的次要选项。下载、保存和去重由后台处理。

统一入口为“参考视频”，支持上传本地视频或粘贴TikTok链接；两种来源进入相同的后续流程。当前默认在对话中直接提供文件/链接与要求。主制片按本轮明确意图使用受限观察工具，目标不清先问一句；任意聊天URL不会自动启动下载。自主创作、复刻与局部借鉴的不同Skill和输入见[模式设计与实现](creation-modes-design.md)。

| 输入来源 | 后台准备 | 分析入口之后 |
| --- | --- | --- |
| 本地视频 | 校验文件、画面及音轨，固定当前字节版本 | 百炼声画理解 |
| TikTok链接 | 获取视频、保存来源、检查画面及音轨，固定当前字节版本 | 同一百炼声画理解 |

**分析视频**：声画理解后交付时间段拆解，说明镜头、动作、口播、音乐/音效、开场与推进、商品证据和可借鉴方法，同时保留不确定项；交付结果不止是素材卡片。

**按此复刻**：先运行相同声画理解，再结合当前商品和用户要求形成复刻方案、脚本与分镜。参考镜头、台词和节奏能否迁移由实际观察与本款依据决定，不能把参考中的性能主张当成本款事实。已知的商品与创作目标直接复用，确实缺少且影响方案的信息才询问。后续生成仍走现有准确方案、参考图和费用确认流程。

开始处理的动作应明确包含一次收费分析，界面简洁展示费用提示，不让用户另外完成一次“导入”再找分析入口。提交参考任务是自动接续依据；仅作为历史资料提及的URL不触发。仅分析交付报告，不写入采用清单。复刻绑定指定参考的任务ID、素材及候选hash，以未经人工核对的观察进入本次创作输入，不写 confirmed_at；随后进入原主制片流程。普通素材分析保留逐条选择采用。

下载成功不代表分析成功；模型失败保留文件，重试分析不重复下载。链接获取失败时在同一参考卡片提供“上传原视频继续”，保留原任务意图和链接来源；不要求新建任务。

### 实现选择

| 方式 | 能力与取舍 |
| --- | --- |
| TikTok Display API | 面向授权创作者；查询校验视频属于该用户，字段无通用MP4下载地址，不适合任意参考链接 |
| TikTok oEmbed | 用于标题、作者和网页嵌入；不能代替视频下载与声画输入 |
| yt-dlp TikTok适配器 | 固定2026.8.19，只离线解析公开页面内的数据；其自身联网入口被禁用。上游页面变化、403、缺声等仍可失败，不承诺所有链接成功 |
| 商业解析API | 暂不引入订阅；公开解析实测成功率不足后再评估稳定性、来源和费用 |
| 用户上传 | 保留为获取失败后的继续入口，保留来源URL；明确文件由用户提供，未验证与URL字节一致 |

获取边界为 `studio/tiktok_reference.py`，固定yt-dlp版本。第一版仅用户主动给出的单条公开视频：`www.tiktok.com/@.../video/<id>`、`vm.tiktok.com`、`vt.tiktok.com`、`www.tiktok.com/t/...`。不要求无水印，不移除来源标识；不接主页批量、直播、私密视频、图集或市场数据采集。产品数据采集继续走既有 `little_else_intel`，不在Studio另建collector、SQLite或评分系统。

### 运行契约

- 沿用JobManager的 `reference_video`、request_id幂等、取消和原事件日志。记录原/规范化URL、视频ID、抓取时间、提取器版本、作者标题、媒体hash与校验结果；来源信息不升级为商品或市场事实。
- 仅HTTPS与明确TikTok路径；短链接每跳校验。对下载器涉及的CDN、DNS解析和实际连接同样约束，阻止私网、回环、链路本地、metadata地址与DNS重绑定，不能只校验初始URL后让依赖任意联网。
- 自有HTTPS下载器逐跳解析并校验全部DNS地址，连接固定数字IP并保留原域名TLS验证；不使用环境代理。全程最多120秒、12次请求，每次最多6跳；页面4 MiB、媒体64 MiB。直接实例化离线TikTok解析器，不加载用户配置、浏览器Cookie或外部进程，不求解挑战、不调用私有API。下载字节经真实解码后才通过原accept_upload保存；临时CDN播放URL不写入来源日志。
- 不把临时播放URL直接交给Omni：先固定本地字节再分析，以免过期、请求头依赖或来源漂移。真实媒体仅放Git外原run目录。
- 优先含画面和声音的格式；下载返回码和扩展名不能替代解码。检查时长、视频轨、音轨覆盖；缺声时显示“下载文件无音轨，原视频声音状态待核实”，不能标为完整声画导入。
- request_id重放复用原Job；同一reference_id固定来源与目标，完成步骤由事件与候选恢复。已下载文件按hash复用，已完成观察不重复调用；复刻失败只重启后续策划。更换参考须新任务，不覆盖同名文件。失败保留URL及手动上传入口；上传续接标明来源为用户文件，未核验它与URL内容相同。

### 验收

新增专项离线测试覆盖来源校验、短链接和跟踪参数、重放、续接、下载与分析复用、来源不可替换、缺声/损坏、取消、私网与重定向、数字IP/TLS绑定、字节超限/截断、固定版本离线解析及费用前置检查。完整回归结果见本节末。尚未用真实TK参考链接测试成功率，也未进行百炼账户扣费与内容识别验收。

本轮验证：后端完整回归1115通过、2跳过；后续关注点传递与界面细节修改后，参考+Omni专项30项通过、下载器专项29项通过；前端271项通过。编码检查712文件通过，git diff --check通过。测试使用隔离运行目录、合成声画视频、假网络和假模型；未发起真实模型调用，未下载实际参考视频。2026-09-21按用户要求更新实际运行环境的固定依赖（yt-dlp 2026.8.19，pip check通过），确认无活动创作任务后重启4760服务。沿用原进程指定的本机恢复数据目录，不迁移运行数据。新页面与参考任务GET接口返回200，实际返回的reference-video.js与仓库文件hash一致，百炼Omni连接可发现，原有两个项目可读取。未进行收费调用或真实TK下载，内容质量仍待实测。
