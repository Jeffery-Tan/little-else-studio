# 独立工作台迭代：实现与验收边界

日期：2026-10-09。依据：[产品总监审查](product-director-audit-20261009.md)及随后确认的 R0–R7 规划。

## 产品原则

对话与作品画布操作同一份作品、引用关系、用户决定和执行记录。先完成三页带货图文工程闭环，再沿同一镜头身份与制作状态验证视频。真实模型与收费媒体的业务验收本轮保持暂停；合成像素、假模型和结构检查不能证明内容质量或商业效果。

继续采用 Python 模块化单体、原项目日志和原制作投影。没有新增数据库、第二套任务状态库、另一位审核 Agent 或另一条审批写入路径。

## 迭代交付

| 阶段 | 实现 | 必须保留的边界 |
| --- | --- | --- |

## 画布与批注

`workspace_objects.py` 从原 Store、Pipeline、`production._read_state_without_service` 投影对象和关系。人物、场景、页/镜是原作品内的只读实体，保持准确 artifact version/hash；可执行参考来自原 DraftIn，不从任意画布连线推导。引用修改沿原 `preserve_prompt_from`、`supersedes` 和准确来源保存新版本。

`canvas_layout_saved` 保存项目视口、坐标、分组和自由笔记，采用 revision 与 request_id 防止覆盖并发编辑。响应未知保留原请求供核对，不擅自生成新请求。分组和笔记不改变执行依赖。

批注写入 `workspace_annotation_saved`；点击批量修改才写真实 UI 选择、原文收件和原 Job。相同写稿版本的多条批注合并成一次工作范围；不同对象依次处理，每次执行前重验准确版本。历史或失效对象可阅读、可留批注，但不会自动改绑当前稿。单批最多 24 条、合计 8000 字，超限明确分批，不截断用户原话。区域坐标绑定图片原指纹，时间点绑定视频原指纹；仅标注位置不等于完成视觉观察。

## 实际结果检查与导出

检查入口单独说明理解模型用量，并冻结连接 revision、准确输出及参考。使用现有图片/视频理解连接读取实际像素或声画，逐项返回 `observed_ok`、`defect` 或 `unknown`、依据和限制。缺失字段、坏结果、源变化和失败不产生通过记录，不自动重试或重新生成；模型观察不写人工批准。视频保留实际输入处理、采样和音轨覆盖的原检查限制。

百炼图片检查可同时读取准确结果与参考图；MiMo 保持现有单图观察范围，原生视频连接保持单视频输入。后两种入口不发送参考图像素，报告明确标注参考一致性未检查，整体结果不得记为完整观察通过。所有检查都需从界面明确发起，不因生成完成自动增加理解模型费用。

整组图文仍用既有 `delivery/photos/download`：必须当前准确采用稿的完整页面齐备，并保留原 caption。新增准确对象导出允许用户选择历史/当前单件文字或结果，明确不是完整交付验收；包含原文件、校验清单、批注与已有检查，不包含密钥、连接配置或模型私有记录。总量最多 256 MiB，超限分批。

## API

| 用途 | 入口 |
| --- | --- |
| 对象图 / 项目布局 | `GET /api/runs/{run_id}/canvas`、`POST /canvas/layout` |
| 准确文字比较 | `POST /api/runs/{run_id}/objects/compare` |
| 批注保存 / 明确执行 | `GET/POST /api/runs/{run_id}/annotations`、`POST /annotations/execute` |
| 实际结果检查 | `GET/POST /api/runs/{run_id}/result-inspections` |
| 准确对象导出 | `POST /api/runs/{run_id}/objects/export` |
| 全任务用量 | `GET /api/runs/{run_id}/tasks/{job_id}/usage` |
| FIFO 文字排队 / 状态 | 原文字任务入口加 `enqueue=true`、`GET /api/jobs/queue` |

上述写入遵守原环回地址、Origin/Host、JSON、安全文件路径、准确版本、request_id 幂等和用户决定边界。自然语言仍通过原消息解释和可信候选进入流程，没有基于关键词的第二套执行器。

新离线验收覆盖复合停止、未知视频保护、父子共享额度、方法快照/升级/来源证据、阶段轮次、自检修复范围、准确对象、布局并发、批注不执行、实际像素输入、不自动批准、导出字节、三页图文局部参考替换、队列、查询并行和单视频远端等待。

三页验收必须通过真实 HTTP/Pipeline 路径使用明确的合成素材和计数假提供方，验证只替换第二页时其余两页原结果保留，新的生成请求仅来自独立显式提交，最后完整导出三页。浏览器验证使用系统临时数据根和独立端口 4781，不写真实 4760 项目。
