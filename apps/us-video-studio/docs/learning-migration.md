- 原研究全文、两份来源登记、TikTok 观察、图文方法和比较报告在站内读取。历史演练包及已登记媒体只读打开，原始字节不改写。

## 实际执行

主控每轮根据完整需求显式选择用途、视频/图文格式及相关案例。角色请求组装时加载 Skill 正文与合资格案例，保存全文快照、Skill/库指纹、种子与依赖案例；产物证据引用这些快照。快照表示组装了哪些输入，不证明提供方已接收、模型正确遵循或质量通过；真实调用情况须核对同轮台账。

新来源、保留测试和仅偏好锚点不进入创作者召回。来源材料只提供表达方法，不提供当前商品规格或效果。审核者取得独立过滤后的方法与上游产物，不读取创作者聊天或本轮局部偏好来替代审核。状态、暂停和反馈路由禁止写稿、派工、编译及发起新审核；明确选择继续后才恢复。

视频和图文共用既有四阶段状态机与采用门禁。图文角色使用逐页购买问题、图内文案与 caption，不强塞时码。站内 `compile_creative_package` 调用既有确定性编译器，生成本 run 的可下载输入包/审阅包；字段见[创作包契约](creative-package-contract.md)。编译绑定准确产物、素材指纹和库版本，原图保留字节，文件及绑定记录变更会被识别。编译不调用生成模型、不烧录图内文字、不产生图审或付费授权。

## 从反馈到下一轮

1. 在「反馈与入库」选择准确产物版本，直接写原话及范围；主控也能从当轮真实用户话语生成待审提案。
2. 页面显示候选与局部差异。用户点击「确认差异，保存入共享库」后才应用；模型没有应用工具。
3. 应用校验原版本/引语、候选指纹与当前库版本。冲突不自动覆盖或重基。共享文件锁阻止多个 Studio 实例同时写库；本 run 留存前后库与操作审计。
4. 未校准反馈仅在原 run 中按版本、范围回流，不因局部认可进入所有后续项目。
5. 新参考可登记已解析 TikTok 视频链接，初始为待研究，不自动抓取。用户添加具体观察、依据、适用策略及限制并审阅差异后，才可取得表达/分镜用途资格；完整声画/效果资格不自动提升。方法可有理由地保留、修订或退役。

入库不等于继续授权，不自动重稿。价格、销量和转化效果没有证据时仍未知。

## 存储与验收

快照与提案在外部数据根的 `runs/<id>/learning/`，编译包在 `runs/<id>/creative-packages/`；没有第二套案例数据库。应用提案会有意修改仓库中的唯一学习库，并保留候选和前后字节作为恢复依据。不要同时用旧 CLI 手工覆盖该文件；旧 CLI 未参与 Studio 文件锁，CAS 只针对已观察到的版本变化。

离线验收覆盖角色实际输入、用途隔离、精确版本和原话、局部差异、跨进程 CAS、重试幂等、两种真实本地编译、路径限制和篡改拒绝。浏览器操作在临时运行和临时库完成，正式库未写模拟反馈。本轮没有真实模型请求或素材生成；此前最小 Codex 连通测试不代替创作能力验证。

## 2026-09-24 独立学习记录与 v2 过渡

`Run.kind` 新增 `learning`；旧 `run.json` 缺此字段时读取为 `creative`，不重写原件。独立学习记录沿用原 `runs/<id>/`、聊天、事件、素材、任务和台账，只读状态由 `GET /api/runs/{id}/learning/session` 投影，不借用四个生产阶段。学习对话只有读取学习记录、比较合资格方法、提出变更和提问工具；上传或阅读不自动分析，声画分析仍走原参考任务确认与台账。分析后可以直接结束，也可以提出可拒绝的变更。

正式库当前是 v1，仍可读。`GET /api/learning/migration-preview` 只计算 v2 候选差异和无法确认的来源市场、方法字段，不写库。学习记录中的迁移提案先把 `before.json`、`after.json`、差异及指纹写到 Git 外；用户阅读后以提案指纹、库指纹和一次请求 ID 确认。应用时先写同目录 `migration-backup.json`，原字节保存在 `before.json`，再以共享库锁和 CAS 原子替换。若库在提案后变化，返回冲突并要求重新预览；不得用旧确认覆盖新库。需要恢复迁移前字节时先停止写入服务，依据该提案目录中的备份和指纹核对，再按当前业务状态制定恢复方案，不直接整文件回退并抹掉后续独立变更。

v2 `LearningDelta` 可以在同一候选中新增案例并创建方法，校验同 Run 的准确分析来源、时间范围、观察文字及证据引用后才允许整体应用；人工素材观察也按原文件指纹与原记录逐条核对，模型观察保留模型身份。待审提案绑定当前用户讨论版本，新用户纠正使旧提案失效。`no_change` 可记录结论而不增加库版本。新建创作 Run 的上下文除了原案例标签检索，还包含合资格方法摘要、适用与排除条件；选中方法后可按库指纹、修订号读取正文、支持与反例。新方法先为 `trial`，默认不进入普通创作；另经用户审阅 `method.activate` 提案后可按限定用途进入常规选择，效果仍标为未验证。创作 Run 首次读取时固定共享库字节，其他 Run 后续更新不会悄悄改变它；同 Run 明确应用的反馈或观察会更新固定版本。`method_usage_recorded` 绑定任务描述、方法修订及准确稿件片段，只表示 Agent 的使用声明，不表示审核通过或效果改善。

若历史创作 Run 已留过学习上下文，但当时没有完整库快照，而且当前库指纹不同，工作台保留其原上下文供回看，拒绝以当前库悄悄补写新的方法目录；需要当前方法时新建项目。

离线测试使用临时库和假模型。正式库尚未执行 v2 迁移，也未完成一条真实视频的学习、新项目脚本对照或市场效果验收；这些结果不能由测试断言代替。
