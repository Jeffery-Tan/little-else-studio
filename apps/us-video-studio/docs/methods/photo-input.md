# 图文审阅包方法卡

适用：US 商品图文的页序、图内文案、caption 与成图核对。来源：[图文配方与命令](https://github.com/Jeffery-Tan/e-business/blob/main/tracks/us/creative/photo-copy/README.md)及[创作包契约](../creative-package-contract.md)。本卡只说明 Studio 当前可执行边界。

1. 先确定每页的购买作用、画面主张、可见商品依据与下一页新增信息。按[共同视觉设计](visual-design.md)引用人物和场景身份，保持人物、服装道具、商品形态与跨页连续性；无人出镜也需要明确环境设计。图内消费者文案及 caption 按本次内容语言输出，默认美式英语。
2. 将计划、逐页文案、来源与拟用图像输入编译为准确版本的本地审阅包；使用 `compile_creative_package(format=photo)`，不要把计划状态当作已生成图片。
3. 生成前核对完整实际输入承接了共同视觉设计及本页内容；真实成图后逐页检查人物与场景、US 处境、商品身份、文字是否真的出现且可读、页序与 caption 是否承接、alt text 是否对应实际图像。工具结构通过不能替代看图。
4. 图片生成、准确图审和费用均走工作台原有用户确认入口；用户未回复不算采用，反馈须绑定具体页与版本。
