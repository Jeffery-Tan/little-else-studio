# 视频制作输入方法卡

适用：US 视频方案已确认，准备本工作台的分镜参考图或视频输入。来源：[从案例到实际制作输入](../../../../tracks/us/creative/learning/execution.md)及[创作包契约](../creative-package-contract.md)。来源中的旧执行器与校准样例不作为 Studio 当前操作指令。

1. 绑定当前 run 已采用的准确方案版本、摘要、商品证据与素材字节。旧批准不继承到新版本。
2. 每镜写清画面、动作、口播或环境声、时长、购买作用及可核验依据。说话方式与台词须进入实际制作输入，不能只留在策划解释里。
3. 使用 `compile_creative_package` 编译准确版本的本地输入包；制作方案走 `prepare_production`，完成文字制作检查后由用户在工作台核对实际输入。
4. 修改人物、台词、镜头顺序、节奏或参考图时，重新检查受影响的整段声画与最终输入。编译和哈希通过只证明一致，不证明创意或表演合格。
5. 图片、视频生成分别由用户在制作界面明确提交。参考图改版须重新送审；未确认的图不能用于视频生成。
