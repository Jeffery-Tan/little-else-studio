# US 带货图片与文案：方法研究与工作流转译

研究日期：2026-09-18。范围：US；使用公开网页、平台原始指南和原始研究。用户已澄清本板块交付带货图片与文案，音乐由 TikTok 发布端添加。这里不研究音乐制作、不要求视频合成，也未生成或发布新素材。

## 研究结论

初版应围绕“这是谁此刻会买的东西、图片证明了什么、下一张解决什么犹豫”设计。漂亮场景、醒目字体和流行语都不能替代本款商品证据。首图可以提出购买理由，后图必须兑现；图内短文帮助理解当前图片，caption补充个人选择理由、使用限制和下一步，避免整段重抄图中文字。

这是一组有来源、待本项目验证的工作方法，不是已验证的爆款公式。所读8个主来源不包含可独立复核的本款成交实验；平台精选业绩、眼动注意力、文案培训例子分别不能当作自然流量带货的因果证明。此轮阅读网页正文与PDF文字，不把它记成完整观看TikTok案例。

| placement | 本轮用途 | 不能直接继承什么 |

## 可封装进初版Skill的七条规则

以下是本项目综合推导，均需在US实际素材与反馈中验证；不是逐字抄用平台公式。

1. **购买任务先于构图。** 先写一个具体处境和待改变的判断：谁在什么时刻、目前怎么解决、哪里不满意、为什么这款值得考虑。来源不足标为受众假设，不能以“年轻女性/宝妈”代替处境。参考S04、S05、S07。
2. **首图承诺有对应证据。** 输出首图想让读者形成的判断、可见商品证据、下一图承接问题。只有真实可证明的容量/结构/背法才能进入承诺；气氛图可以表达向往，但不可伪造使用结果。参考S01、S02、S05。
3. **每图承担一个主要购买问题。** 后图可分别回答装什么、如何取用、背在身上多大、哪些情形适合。若两图只有景别差异而无新增信息，合并或删去；不为了固定张数补图。参考S02、S04、S05。
4. **人和场景要承担证明任务。** 人物可解释尺寸、腾出手、穿搭或真实使用姿态；环境解释何时需要。不要以同质模特氛围图替代开口、内袋、比例等关键证据。参考S04、S05、S06。
5. **文字分工并保留人味。** 图内文字解释当前可见信息或提示一个问题；caption解释为什么如此选择、使用上的小取舍、购买前应知道的条件。具体动词和生活理由优先，长短服从理解任务；不机械删除所有口语，也不为了活人感增加无关语气词。参考S01、S07、S08；caption分工为本项目设计假设。
6. **产品事实与生成表现分开验收。** 每项功能/尺寸/材质/价格主张挂接本款证据；生成图逐图检查颜色、结构、数量、相对比例、接触和遮挡。照片般逼真并不能证明容量或性能。无法证明则改表达，不凭AI画面补事实。此为项目质量约束，参考S03–S05的信息真实性要求。
7. **发布与实验分开。** 导出有序图片、纯图版本、图内文本、caption、证据表和待核项；音乐状态固定`platform_added`。发布后按内容版本记录实际曝光/点击/订单及观察窗口，指标缺失保持未知。工具可查完整性，购买理由成立和图片可信仍需实际查看。参考S01，实验安排为项目方法。

### 不采用的机械规则

- **“永远3张/永远9张”。** S01建议2–5图，S02广告指南提到3或7–9图；用途和数据条件不同，均不足以成为我们硬编码张数。以信息需要决定，再测试。
- **“首图只要足够好看”。** 首图有注意力却没有商品身份/购买相关性，会留下无购买方向的漂亮图。
- **“所有图都必须能任意打乱”。** 连续叙事依赖顺序；广告自动封面/排序会改变阅读起点。若使用该功能，需检查每个可能首图是否成立；不为原生图文假设此功能已开。
- **“人味等于第一人称假装买家”。** 可以模拟讨论语气，不能编造购买、长期使用、效果保证或用户评价。
- **“都写成短句，就不会呆”。** S07支持具体含义，S08显示文案形式效应依产品而异。删去理由只剩“Great bag. Shop now.”仍然空。
- **“参考图证明容量”。** AI生成装满图不是实测；装载数量、保温时长、承重、尺寸兼容等需要本款事实。

## 初版输出合同建议

Skill由助手填写，不额外让Jeffery做表：

```text
placement / product_family_id / variant / intended_audience_hypothesis
buying_situation / existing_alternative / belief_to_change
one_core_promise / product_evidence_refs / unknowns
slides[]:
  role / buyer_question / visible_proof / composition
  on_image_copy / product_identity_constraints / evidence_ref
caption / caption_added_information / honest_limitations
image_generation_brief / image_review_findings
music = platform_added
publication_eligibility = unverified_until_account_checked
validation = draft_or_human_reviewed / commercial_effect = unknown
```

证据不足时可完成构图草案及待核清单；不能把不存在的包结构、真人推荐或产品性能填成既有事实。图生成服务与费用仍按已有授权边界执行。

## 零付费验证练习

以已知包款做文本层校准，**下列仅示例，不是本款实测或待发布文案**：

| 不合格提案 | 为什么退回 | 可继续方向 |
| --- | --- | --- |
| 首图“Fits everything”＋AI塞满物品 | 无限容量承诺，AI装载不是证据 | 从已核验装载照片/清单挑一个具体任务；未知则只规划实拍证明 |
| 5张同色包在不同豪华场景 | 无信息推进，不能回答怎么买 | 先列尺寸/开口/携带方式等真实购买问题，再决定所需角度 |
| 图内、caption都写“Stylish. Practical. Perfect.” | 空泛形容、语义重复、没有选择理由 | 指定使用时刻、实际动作与一个小取舍，仍须本款支撑 |
| 虚构“Bought it last month and everyone asks” | 伪造亲身经历和社交证明 | 改成可验证的产品观察或明确假设的场景表达 |
| 自然图文的促销叠字直接导出PDP首图 | 混用发布位要求 | 保留纯实物源图，PDP按单独规则校验，不默认AI渲染合格 |

最低通过标准：外部人能说明“适合谁、为何考虑、图里哪处支持、尚有什么未知”；不能靠作者补长篇解释才懂。机器检查只覆盖字段/来源/版本，不能宣布通过购买说服力测试。实际发布效果应另行积累。
